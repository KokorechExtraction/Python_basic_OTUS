# Создание телефонного справочкника без использования ООП

# 1. Описание проекта

Цель проекта - создание тестов и отладка ранее созданного телефонного справочника на основе паттерна MVC

Программа было отлажена по сравнению с ДЗ №2

# 2. Основные функции

В справочнике предусмотрены следующие основные классы:

1) Phonebook
2) Contact
3) IOClass
4) Reader
5) Writer
6) Console
7) CustomExceptions

Описание смотри в дотстригах

# 3. Структура проекта

model - содержит основную модель, набор исключений, data_ru (набор текста для перевода)
view - все для ввода вывода
controller - взаимосвязь
test - набор тестов
